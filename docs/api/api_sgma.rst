Spectral Graph Modal Analysis
==================================

SGMA performs joint spatial-temporal wavelet transforms on graph signals to
identify oscillatory modes in the wavenumber-frequency domain. The SGWT is
constructed from the graph Laplacian :math:`\mathscr{L}`, whose eigenvalues
:math:`\lambda` correspond to squared wavenumber :math:`k^2`.
